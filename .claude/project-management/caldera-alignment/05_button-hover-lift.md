# 05 — button-hover-lift

## What

Add `hover:-translate-y-px transition-transform` to the global UButton base via `app/assets/css/main.css` or Nuxt UI theme override in `app/app.config.ts`.

Caldera reference: `.btn:hover { transform: translateY(-1px) }` on all button variants.

## Verify

All UButton instances lift 1px on hover.
